# Aura Orthodontics Frontend Template

Premium multi-page orthodontic website ecosystem built with HTML5, TailwindCSS CDN, custom CSS, and vanilla JavaScript.

## Structure

```text
.
|-- index.html
|-- about.html
|-- treatments.html
|-- invisalign.html
|-- braces.html
|-- pricing.html
|-- financing.html
|-- before-after.html
|-- testimonials.html
|-- blog.html
|-- faq.html
|-- contact.html
|-- locations.html
|-- smile-quiz.html
|-- booking.html
|-- virtual-consultation.html
|-- offers.html
|-- css/
|   `-- styles.css
`-- js/
    `-- main.js
```

## Included

- Shared responsive navbar and footer
- Mobile-first luxury healthcare styling
- Sticky CTA and floating WhatsApp button
- Exit-intent offer popup
- Financing calculator
- Multi-step smile quiz
- CRM-ready forms with success states
- Countdown offer widgets
- Review slider layout
- AI smile assessment UI placeholder
- Structured schema placeholders
- Local SEO and service page structure

Open `index.html` in a browser to view the template. Internet access is required for Tailwind CDN, Google Fonts, and remote stock image placeholders.
